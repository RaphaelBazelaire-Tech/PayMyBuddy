# Variables d'environnement

Certaines variables d'environnement doivent être modifiés dans le fichier ```application.properties``` pour être fonctionnel.
> spring.datasource.url - ${DB_URL} - Modifiez le lien de connexion ainsi que la base de données.

> spring.datasource.username - ${DB_USERNAME} - Renseignez l'identifiant pour la connexion.

> spring.datasource.password - ${DB_PASSWORD} - Renseignez le mot de passe pour la connexion.
